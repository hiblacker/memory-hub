# 安全与隐私

## 威胁模型

主要风险包括：局域网未授权访问、来源 API Key 泄露、对话中夹带密钥、恶意导入文件、Prompt Injection、思源 Token 泄露、自动规则误归档和供应链依赖风险。

## 数据分级

- 普通：公开项目背景和一般偏好。
- 私密：个人信息、非公开项目细节，只允许人工归档或明确规则。
- 严格私密：密码、Token、私钥、认证 Cookie、身份证明和财务医疗数据；阻止模型发送与思源归档。

## 密钥管理

- 思源 Token、模型密钥和管理员初始 Token 使用 Docker Secret。
- 数据库只保存来源 API Key 的 Argon2id 哈希、前缀和最后使用时间。
- UI 永不回显完整密钥；日志使用结构化字段脱敏。
- 导出诊断包前再次运行密钥扫描。

## 网络边界

- 默认局域网/VPN 部署，API 要求认证，CORS 只允许管理端来源。
- 思源 URL 仅管理员配置，并限制为明确允许的 HTTP(S) 地址，防止 SSRF。
- 导入器不下载对话中的链接或附件。
- 浏览器扩展只申请 ChatGPT 域名和 MemoryHub 地址所需的最小权限。

## 内容安全

- 对话内容是不可信输入，不能通过文字改变系统规则、归档路径或权限。
- LLM 只返回严格 JSON Schema；非法输出进入人工队列。
- 自动归档规则使用声明式白名单字段，不执行 JavaScript、SQL 或模板表达式。
- Markdown 输出在管理端渲染前进行清洗；思源路径移除 `..`、控制字符和非法分隔符。

## 自动归档保护

自动归档必须同时满足：规则已启用、敏感检查通过、候选无冲突、置信度达到阈值、目标可用、幂等检查通过。涉及删除、覆盖或降低敏感等级的动作永远要求人工确认。

## 保留与删除

- 原始事件默认保留 90 天，可由管理员缩短。
- 候选和版本长期保留，除非用户明确删除。
- 删除操作记录审计事件；已经写入思源的内容不会由数据库删除自动触发远端删除。
- 备份中的数据按备份生命周期延迟清除，界面需明确提示。

## 供应链

- 锁定 pnpm lockfile 和容器镜像 digest。
- CI 执行依赖审计、镜像漏洞扫描和 secret scanning。
- 避免直接复制 AGPL 或带品牌限制项目的实现代码；只复用公开设计理念。
